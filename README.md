## Featured Projects

The portfolio currently showcases the following projects:

### AI Receipt Scanner

An AI-powered document and receipt processing application that extracts structured transaction information from receipt images using a vision-language model.

**Technologies:** Python, Streamlit, Groq API, Qwen Vision Model, PostgreSQL, Neon, Docker

### Flight Price Prediction API

A machine learning application that predicts flight prices from flight-related features and exposes the trained model through a REST API.

**Technologies:** Python, Pandas, Scikit-learn, LightGBM, FastAPI, Docker, REST API

### Fraud Detection

A machine learning classification project designed to identify potentially fraudulent transactions from transaction data.

**Technologies:** Python, Pandas, Scikit-learn, XGBoost, Feature Engineering, Model Evaluation

### Customer Churn Prediction

A machine learning application that predicts customers who are likely to churn and provides predictions through an interactive interface.

**Technologies:** Python, Pandas, Scikit-learn, Random Forest, Logistic Regression, XGBoost, Streamlit

More details about each project, including the problem, approach, tools, results, source code, and live applications where available, can be found on the portfolio website.
